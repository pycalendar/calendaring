# Sync/async architecture prototypes (roadmap 0.2)

Throwaway prototypes backing
[`docs/design/SYNC_ASYNC_ARCHITECTURE.md`](../../docs/design/SYNC_ASYNC_ARCHITECTURE.md).
They exist so the comparison rests on measurements rather than on opinion, and
so the numbers can be re-derived after the design changes. **None of this is
library code** — 1.3 implements the chosen design properly.

From the repository root:

    python -m pytest prototypes/sync_async/ -q              # 110 passed, 1 xfailed (all tools)
    python prototypes/sync_async/p4_codegen/generate.py     # regenerate p4's _sync/ copy
    python prototypes/sync_async/measure.py                 # every number and output block
    python prototypes/sync_async/check_ast.py               # exit 0 on the real modules

The xfail is caldav's silent-discard bug, applied as a **strict** marker: it
asserts that the server was not written to, and it will fail the suite if the bug
ever stops reproducing.

| File | |
|---|---|
| `common.py` | toy backend, sync/async/filesystem transports, fake server |
| `p1_dual_mode.py` | runtime dual-mode (caldav 3.x) — the control |
| `p2_sansio.py` | generator-based Sans-I/O |
| `p2_sansio_bug.py` | two planted shapes of the composition mistake: the public-name call the guard catches, and the dropped `_io_` generator only a static check catches |
| `p2_typed.py` | the same core plus typed façades — one of the two remaining candidates |
| `p3_greenlet.py` | greenlet bridging (SQLAlchemy pattern) |
| `p4_codegen/` | async-first, sync generated by `unasync` and committed — the other remaining candidate |
| `test_conformance.py` | one suite, 5 prototypes × 2 modes |
| `typing_probe/` | three cases put to mypy per prototype |
| `p4_codegen/_async/buggy.py` | three shapes of the missing-await slip, for the type-checker test |
| `measure.py` | lines of code, scaling, traceback quality |
| `check_ast.py` | p2b's static check — relevant only if p2b is chosen |

`pytest-asyncio`, `greenlet`, `unasync` and `mypy` are needed for the full run
(pyright too, for its column in `measure.py`). Without `unasync` or `mypy` the
tests that need them skip — or fail, if `CI` is set:

    uv run --python 3.14 --with unasync --with pytest --with pytest-asyncio \
        --with greenlet --with mypy python -m pytest prototypes/sync_async/ -q

The numbers in the document are from Python 3.14; greenlet's traceback is
shorter on 3.13.
